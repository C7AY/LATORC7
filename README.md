# LATORC7

**LATORC7** - легковесный инструмент для быстрого перевода текста с английского на русский и обратно, предназначенный для использования повседневно вызывается горячими клавишами CTRL+SHIFT+T, если запущен, этими же клавишами можно его скрыть обратно в трей.

## 📋 Описание

LATORC7 позволяет мгновенно переводить текст прямо из системного тря. Приложение поддерживает два направления перевода: английский → русский и русский → английский. Идеально подходит для быстрого обмена информацией между языками без необходимости открывать отдельные окна или использовать внешние сервисы.

## 🚀 Особенности

- **Быстрый доступ**: Программа работает в системном трее, вызывается глобальными клавишами
- **Глобальные горячие клавиши**: Ctrl+Shift+T для показа/сворачивания приложения
- **Двусторонний перевод**: Поддержка перевода с английского на русский и наоборот
- **Удобный интерфейс**: Два текстовых поля для ввода и вывода перевода
- **Интеграция с буфером обмена**: Быстрое копирование текста (кнопки копирования)
- **Сворачивание в трей**: При закрытии окна программа сворачивается в системный трей
- **Простота использования**: Минимальный интерфейс без лишних функций

## 🛠️ Требования

- Windows 7/8/10/11 (32 или 64-bit)
- Подключение к интернету для работы с переводчиком Google Translate

## 🔧 Установка

1. Скачайте последнюю версию из раздела Releases
2. Распакуйте архив в удобное место
3. Запустите LATORC7.exe
4. Приложение автоматически добавится в системный трей

## ⌨️ Глобальные горячие клавиши

- **Ctrl+Shift+T** - Показать/свернуть приложение в трей

## 📝 Использование

1. Введите текст в левое поле (English)
2. Нажмите кнопку перевода
3. Полученный перевод появится в правом поле (Russian)
4. Используйте кнопки копирования для сохранения текста в буфер обмена
5. Для смены направления перевода используйте кнопку "CHANGE"
